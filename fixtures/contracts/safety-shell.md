# ADR-0002 shell fixtures

The actor is the unprivileged Nix build user. Each case provisions its own temporary root and lock where applicable. The [Bash runner](../../assets/safety/shell/test-operations.sh) sources the packaged library. Faults affect only temporary fixture data.

| Case | Pre-state and operation | Expected result and observations |
| --- | --- | --- |
| `INTENT-01` | Try publication without a stage, invalid leaves, and missing or symlink lock entries. | `Denied`. No new lock, stage or final. The symlink referent is intact. The caller owns approval and any read-only or dry-run entry point. |
| `BOUNDARY-01` | Try relative and traversal roots, final and ancestor symlinks, a non-directory, and a group-writable root. Move the root after staging and install a replacement path. Inject `EXDEV` at link. | `Unsupported`. No publication in either root after the move. The old stage remains for inspection. Cross-device refusal runs through native errno handling. There is no cross-directory publish operation. |
| `LOCK-01` | One shell takes the fixed lock and launches a child with the inherited stage and lock descriptors. A second process tries the same lock before and after the first shell is killed. | Contention persists while the child can write. The child completes a later write. Reacquisition after the child exits uses the original lock inode. The guarantee applies to cooperating processes on that inode. |
| `PUBLISH-01` | Write and validate data with a restrictive caller umask. Separately collide with regular, symlink, dangling symlink, directory-target symlink and directory leaves. | The success case produces a single 0600 final with validated bytes. Collisions return `Conflict` across reruns. Compare type, inode, mode, bytes, link targets, and the contents of directories and referents. |
| `PUBLISH-02` | Exercise partial producer writes, synthetic writer ENOSPC, validation failure, cancellation and TERM. Record the successful sequence of file fsync, link and parent fsync with all calls forwarded. Inject errno separately at file fsync, link and parent fsync. Interrupt immediately after a real link. Move the root after link and after parent fsync. | Preserve producer, validator and signal statuses. Pre-link failures and definitive link failures leave no final. An ambiguous link error retains the stage and reports `OutcomeUnknown`. A parent fsync error, post-link TERM or failed observation can leave a visible final and stage. Assert call order, status, diagnostics and entries. |
| `OWNED-01` | Move the owned stage aside and install a different regular file at its stage name. | Refuse publication and cleanup. Both the original data and the substitute survive. |
| `RECOVERY-01` | Rerun with the stage abandoned in `LOCK-01`. Remove root write permission before EXIT to make cleanup fail, both before and after publication. | Rerun publishes once and leaves the abandoned stage and unrelated entry alone. A further rerun preserves the final on conflict. Cleanup failure preserves a prior exit status or reports failure alongside a confirmed final. |

This suite exercises namespace changes at controlled points. Coverage excludes adversarial races against the trusted parent and stage entry, real cross-mount and ENOSPC setups, power loss, host acceptance and cross-language contention. The fixture IDs describe evidence for this Bash implementation.
